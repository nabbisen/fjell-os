## What this release is

**E-070**, **E-071**, **E-072**, **E-074**), **four filed, unscheduled**
(**E-073**, **E-075**, **E-076**, **E-077**). The milestone's spine is that

gate exists to notice when the next one cannot.

not ask for one**, indistinguishable from a real digest (**E-076**),
disclosed in the CHANGELOG in its own words — the condition the architect
attached to this cut, in the same struct and milestone that added
`DiagnosticBundle::audit_available` so the audit section could not be
silently empty the same way.

## What shipped

### RFC-0.35-001 — the capabilities the update path never had

Five services addressed their peers through CSpace slots `spawn.rs` never
installs; two busy-spun on the absence for the lifetime of every boot.
`fjell-upgraded`'s update-index fetch had never completed against a real
`secure-transportd` — the vanishing message underneath it is the same gap
seen from inside the service that needed the channel. A new
capability-topology consistency-check subcheck discovers the universe of
declared slots from the services' own sources recursively (not `main.rs`
alone), fails on any slot neither installed nor waived to a named line, and
survived two review rounds probing it against shapes it did not originally
catch: a slot declared outside `main.rs`, a service naming another tool's
flag by accident. The busy-spins now yield and disclose the receive error
once. Closes **E-070**, **E-072** (the two remaining installs, `attestd`
and `netd`, carried out as **E-074** rather than left inside a closed
entry).

### RFC-0.35-002 — protocols and authority nobody serves

`fjell-diagnosticsd` sent an `AUDIT_QUERY` protocol `fjell-auditd` had
never implemented; `fjell-secure-transportd` declared four client
endpoints while receiving on one, under a comment claiming a round-robin
over three. Both were a component claiming a conversation that does not
happen. The audit query protocol is retracted rather than implemented
against nothing: `recv_msg` returns a `Result` a caller can tell "no
records" from "not implemented" with, and `DiagnosticBundle::
audit_available` says honestly when the audit section is empty. The false
round-robin claim is withdrawn from its own comment. Closes **E-068**,
**E-069**, **E-074**.

### RFC-0.35-003 — instruments that answer the question you asked

`fjell-repro-check` silently accepted any unrecognised flag — including
`--help`, which it did not have — and fell through to its full two-build
mode, able to race a live `test-all`. The same defect, fixed the same way,
in `fjell-mmio-audit` and `fjell-unsafe-audit`; the sweep that fixed the
latter surfaced a live caller bug (four call sites and three documentation
pages passing it the other tool's flag name, silently discarded). All
three tools now reject an unrecognised argument, answer `--help` without
building, and exit 2 for a usage error, 1 for a real finding.
`v1-readiness.md`'s own summary — which had twice silently disagreed with
the matrix it summarises — is now Gate 12's 20th subcheck,
`readiness-summary`. Closes **E-071**.

### RFC-0.35-004 — two digests that describe themselves

`fjell-measure-format`'s chain digest and `fjell-bundle-format`'s bundle
digest were the last two of the format census (RFC-0.33-003) with no
generated description. Both moved onto the project's `Canon` trait, which
gained exactly one new primitive (a big-endian `u32`) and left the
eighteen existing descriptions unchanged, checked against digests and raw
byte streams captured from the unmodified encoders before either moved.
Review found one more gap before closing: the chain digest's fixed,
always-32-byte metadata slot was not stated as such in its generated file,
so a second implementation could have padded or omitted it and produced a
different digest — fixed with a `Canon::note` on the field, the same
mechanism already used for the bundle digest's unlengthed `name`. Closes
**E-065** — the census is complete: twenty generated files, two remaining
survivors (**E-073**).

## What this release does not claim

- **That a diagnostic bundle's measurement-head field is honest about
  failure.** It is not — **E-076**, disclosed plainly in the CHANGELOG, not
  only cited by number.
- **That `fjell-secure-transportd` or `fjell-diagnosticsd`'s readiness
  announcements reach `service-manager`.** They do not — **E-075**, both
  comments now withdraw the claim rather than state it.
- **That a clean dependency check describes what Fjell OS ships.** The
  published crates and the kernel have no third-party dependencies at all;
  the check covers tools, tests, benchmarks and the development-grade
  crypto crate, and says so in its own output.
- **That `fjell-audit-format`'s or `fjell-net-format`'s on-wire layouts
  have a generated description.** They do not — **E-073**, the census's
  last two survivors, pending a kernel-side change to where
  `sys_audit_drain` writes.
- **That CI gates the release.** Criteria 9 and 11 *record* CI; every gate
  runs locally.
- **Cross-machine reproducibility**, as at every previous release.

## The implementer's own findings this cut, recorded

1. **Root `README.md`'s version badge and "Current version" line were
   still `0.34.0` after the bump** — missed in the first pass, caught by
   `version-currency` on a full `consistency-check --all` run before moving
   on. Fixed in the same commit as the RFC move (`a7e1b7c`).
2. **The trust-report ordering hazard, caught by looking rather than by a
   gate.** `release-rehearsal`'s Gate 6 regenerates the report for real;
   run before `test-all` finished, it cited a run with no summary. Not
   committed — the real run's regeneration is what landed.
3. **A self-inflicted `test-all` kill via `head -20` on a `--help` probe
   that subcommand does not have.** `test_all.rs` falls through to the
   full run on any unrecognised flag, the same shape RFC-0.35-003 closed
   elsewhere — but that line's own sweep had already judged this file safe
   for every internal caller, since the toggle only ever *reduces* scope
   from the default full run. Correct for a caller; less so for an
   operator typing `--help` by hand and burning a full run by accident.
   Noted rather than filed: no caller passes it a mismatched flag, so
   there is no live caller-bug, only a wasted run.
