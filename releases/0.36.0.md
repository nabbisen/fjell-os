## What this release is

Two RFCs, **five errata closed** (**E-075**, **E-076**, **E-077**,
**E-079**, **E-080**). Four of the five are inside one component,
`fjell-diagnosticsd` — a signed diagnostic bundle stopped claiming
measurements it never took, stopped carrying a record it invented, and
started covering the two fields its own specification always said it
signed.

**`fjell-diagnosticsd` still cannot be asked for anything** (E-078),
disclosed in the CHANGELOG in its own words — the condition the architect
attached to this cut. Closing four errata inside that service makes it
honest about what it would report if it could run; it does not make it
run.

## What shipped

### RFC-0.36-001 — a field must say what it is

`fjell-diagnosticsd`'s bundle builder reported a 32-byte zero digest as a
measurement head whenever its query to `measuredd` failed, with nothing
distinguishing absence from a real digest that happens to be zero
(**E-076**). The same function passed a literal zero as the bundle's
attestation digest and a literal `1` as its keyring anchor epoch — neither
ever queried — and called `add_intent` with hardcoded arguments asserting
an update staging was confirmed two seconds ago, whether or not anything
of the kind happened: a fabricated record inside an artefact the builder
signs (**E-079**, found by the sweep E-076's own entry called for,
including a fifth instance found mid-implementation and escalated to the
architect before any code was written against it). Separately, the signed
digest never covered the trust provider or key epoch at all, though the
governing specification has always listed both (**E-080**).

`DiagnosticBundle` gains three availability flags, each beside the field
it qualifies, settable `true` only by the code that actually obtained a
value; the digest zeroes a field whenever its flag says unavailable,
regardless of what the struct holds. The fabricated intent is deleted
outright, and the bundle builder's constructor no longer accepts a
parameter that could receive a fabricated epoch or attestation digest at
all. The digest now covers the trust provider and key epoch, in the
specification's own order, demonstrated failing against the unmodified
encoder before passing against the fix. Two services (`secure-transportd`,
`diagnosticsd`) that announced readiness to a slot nobody installed or
their own identity endpoint now send through the slot every other service
uses, with a new observable confirming `service-manager` genuinely
observed both. Closes **E-075**, **E-076**, **E-079**, **E-080**.

### RFC-0.36-002 — a benchmark flag that does what it says

`cargo xtask bench`'s unrecognised flags matched neither `--baseline` nor
`--check` and silently fell through to the cheapest default: run the
benches, print the results, exit success. An unrecognised argument now
exits 2 with its usage printed; `--help`/`-h` exit 0 without running a
benchmark. The exit code was shown surviving `fjell-tools`' own dispatcher
at the shell, not only returned from the function. Closes **E-077**.
