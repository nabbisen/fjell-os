## What this release is

The first line in this project to add **runtime behaviour** rather than
documentation or tooling, and the first in which its distinguishing
architectural bet actually runs.

- **RFC-v0.23-001 — ABDD live path.** A service emits meaning, a *separate*
  proxy task renders it, and the return leg is capability-checked with the
  refusal demonstrated. `fjell-init` no longer links `fjell-proxy-text`, which
  removes a standing architectural violation: it had been emitting and
  rendering in one address space across 13 call sites.
- **RFC-v0.23-002 — milestone markers by identity.** Markers now attest the
  service they name rather than whatever task occupies a hardcoded table index.

## Findings during preparation

**`cargo fmt --all --check` failed** on an import block in `dispatch.rs` from the
marker work. Cause: **the architect omitted the fmt check from RFC-v0.23-002's
required-evidence list**, which every earlier handoff had carried. The
implementer satisfied the list they were given. Corrected mechanically with
`cargo fmt --all`; one file changed. Recorded because the omission is
instructive — a missing item in an evidence list is indistinguishable, from the
implementer's side, from an item that does not matter.

## Known limitations at 0.23.0

| Limitation | Disposition |
|---|---|
| **E-013** — `fjell-kernel` declares only `[[bin]]`, so `test-all` tier 1's `cargo test --workspace --lib` skips it silently. Five `#[cfg(test)]` modules have never executed under the tier that claims to run them, including `lease/mod.rs`, the kernel-side half of a Verus release-required target | ACCEPTED, deferred. Own RFC after this release; the fix is architectural |
| **E-012** — v1.0 checklist Step 9 signs a build output that does not exist | ACCEPTED, deferred to v1.0 preparation |
| The nine declared-but-undispatched syscalls | Undecided, and now with a concrete cost: `DmaShare` blocked the documented bulk-transfer path, forcing chunked transfer |
| Chunked semantic transfer costs ~314 blocking round trips per emission-plus-forward | Acceptable for a demonstration; not a designed transport |
| Build-output non-determinism (Finding C, 9 of 28 prebuilt binaries) | v0.22 candidate, unresolved; confirmed cross-environment, not within-environment |
| ABI snapshot gate is formatting-sensitive by design | Recorded trade-off |
| `renderer.rs`'s `ingest` catalog-codec subsystem (~540 lines) is called by nothing but its own tests | Open question: unfinished successor, or work to retire |

Unaffected: all v1.0-scoped limitations in `docs/release/v1-limitations.md`.
This is a v0.x release; Gate 9 remains unsigned and out of scope.
