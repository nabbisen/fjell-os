## What shipped

### RFC-0.29-001 — 305 tests that nothing ran

Tier 1 was `cargo test --workspace --lib`. **`fjell-tools` and
`fjell-consistency-check` have no lib target**, so none of their tests ran —
including the 36 behind `SYSCALL-CALLSITE-001`/`-002`, added the week before,
and the tests behind all ten of Gate 12's subchecks. **A regression in a guard
would have been caught by nothing.**

A new tier runs **800 tests**, with the exclude set derived from
`cargo metadata`.

**The finding of the line was a side effect:** excluding the 31 `no_std`
binaries removed the dependency edge that had been silently enabling
`fjell-sxt-crypto`'s `crypto-profile-development` feature through Cargo's
feature unification. A crate that refuses to compile without an explicit
acknowledgement was compiling anyway. The identical masking in
`ci-test-v07-formats` was named, not quietly fixed.

Five lists describing the negative categories became one derived answer.
`semantic`, `uart-rx` and `uart-rx-unbound` had run in `test-all` and never in
CI. Closes **E-013**; reduced **E-015**.

### RFC-0.29-002 — the gate that could not see what it blocks on

Gate 7 ran `grep -c "| OPEN |"`. An erratum written `| OPEN (blocked on X) |`
counted **zero**, and the register already writes one status cell that way.
**Gate 7 has never had to work** — nothing has been `OPEN` since the register
was created.

Verified independently at review, on the real register: the old predicate
reported `0`; the new one reports `[FAIL] 1 OPEN errata`.

Six more instruments repaired, each demonstrated on the input it missed.
**Gate 6 discarded the trust report's regeneration exit status** and counted
markers in whatever file was on disk — demonstrated with a real
`Permission denied`. The register now has one parser rather than four.

Closes **E-015**, **E-017**. **E-014 stays open**, two instances named: a shared
TOML array parser, and `errata-tracking`'s blindness to the `**Tracks.**`
convention — where a fix was built, found in testing to break a legitimate case,
and reverted.

## The architect's own errors this milestone, recorded

Three, all in the same family as the work:

1. **The crate count.** I re-derived "23 of 93 never named in CI" by globbing
   `Cargo.toml`; `cargo metadata` says **21 of 91**. My method swept in two
   non-members, and I replaced a correct figure with a wrong one **inside an RFC
   about hand-derived lists going stale.**
2. **The `sound` row count.** I counted 21; there are **22**. My predicate
   required the literal `**sound**`, and `ci-verus`'s heading reads
   `**sound (by explicit design)**`. **A bolded parenthetical defeated my
   count — the identical shape as `| OPEN (blocked on X) |` defeating Gate 7**,
   the finding the same RFC leads with.
3. **A phantom finding.** I reported that discrepancy as *"one of the two is
   wrong"* about the audit's summary table. The table was right the whole time.

Each was found by the implementation model re-deriving a number I asserted.
**That is now eight consecutive lines.**
