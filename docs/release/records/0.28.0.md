## What this release is

Five RFCs, **eight errata closed**, nothing slipped.

The pattern of the milestone is worth naming because it repeated five times:
**every line's scoping was wrong in the same direction.** The defect was always
larger than the erratum described, and always one level below where it was being
looked for. Readiness was broken by a routing table nobody associated with
readiness; a missing register was one of three bugs across 35 blocks; a
double syscall turned out to be the *wrong* syscall; three tools disagreed about
what the repository even is.

Every one of those was found by the implementation model re-deriving a number
the architect had asserted. **Five consecutive lines corrected one of my
counts**, and this cut's own criterion-8 pass corrected three more — including a
tally in a CHANGELOG entry written ten minutes earlier.

## Known limitations carried into this release

**37 errata: 0 OPEN, 24 CLOSED, 13 ACCEPTED.** The four filed this milestone and
still open:

- **E-034** — four `send` helpers take a payload word the kernel has never
  transmitted; the discard was made explicit, which silenced the compiler.
- **E-035** — the ABI baseline had never been re-recorded. Closed as a
  *procedure* this cut; the erratum remains because nothing enforces the step.
- **E-036** — the threat model's T20 names a two-build reproducibility check as
  its defence. **That check is invoked nowhere**; every call is `--skip-build`.
- **E-037** — the toolchain is declared in both `rust-toolchain.toml` and
  `ci.yml`, floats within `1.91.x`, and is recorded with no artefact.

**E-036 and E-037 insulate each other**, which is why neither has bitten.

## What this release does not claim

- **Not that builds are reproducible across machines or time.** E-036: what is
  verified is that committed binaries still hash to a baseline recorded from
  those same binaries on the same machine.
- **No conformity with anything.** 15 of the standards mapping's 37 rows are
  `unassessed` because IEC 62443-4-1/4-2 are paywalled and unread.
- **No hardware.** Nothing here has run on silicon.
