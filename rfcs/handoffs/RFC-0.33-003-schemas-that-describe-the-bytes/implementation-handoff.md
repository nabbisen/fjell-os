# Developer Handoff — RFC-0.33-003

**Governing RFC:** [RFC-0.33-003](../../accepted/RFC-0.33-003-schemas-that-describe-the-bytes.md)
**Milestone:** 0.33
**Status:** inherited from the governing RFC (Accepted, 2026-09-24)
**Audience:** implementation model

This handoff directs execution. It does not redefine the RFC. If you find a
design conflict, **stop and escalate** — do not resolve it in code.

---

## 0. The measure of this line

Not "eleven files exist and are non-empty" — that is the check being replaced.
**The measure is that a change to a struct's bytes cannot be committed without
either the file changing with it or a gate going red.** Eleven hand-written files
asserting `# generated by fjell-tools schema dump`, with no such subcommand, is
the defect; a twelfth hand-written file would be the same defect.

## 0.1 Do this first, and it may change the shape of everything after

**§A is the line.** A generator that hard-codes each format's fields is E-045
again with more steps: two hand-written descriptions instead of one, and nothing
says which is wrong. Before writing a generator, establish **how it learns a
layout** — and if the honest answer is that it cannot without a macro or a
build-time step, say so in writing and answer the RFC's Risks question instead:
**should the frozen file describe the encoder's output rather than the struct?**

That alternative is not a fallback. For the two disk structures the encoder is
what reaches the disk, and D5 is about to make the encoder the only writer.

## 0.2 The window is open, and this line is why it matters

Verified at acceptance and to be re-verified by R1 **at your tip**: nothing reads
any of these formats back from disk — `storaged`'s `READ_CHUNK` is still
`reply(READ_CHUNK); // placeholder`, and `bootctl` builds its block in memory. So
D5's byte change is free **today**. `init` already writes a `BootControlBlock` to
both mirrors; the moment anything parses one, D5 is a migration and out of scope.
**Order accordingly (§D): E-055's serialisation first, then regenerate.**

## 0.3 Settled — do not re-open

1. A `.frozen` file is **generated**, or it does not exist (D1).
2. A comparison **fails on drift, naming the field**, in Gate 1 (D2).
3. Drift resolves **toward the code**, and each corrected file carries a **dated
   note of what it used to claim** (D3).
4. `schema_version` moves where bytes or layout moved (D4).
5. E-055's four sites **serialise named fields**; no padding is written (D5).
6. Every format written to disk or sent over IPC has a file **or a recorded
   reason** (D6). "Nobody wrote one" is not a reason.
7. Three demonstrations, reverted (D7).

## 1. Order

**R1 (re-derive, all eleven, plus the read-back question) → §A–§E in writing →
R5 (D5's serialisation, bytes change) → R3 (generator + comparison + Gate 1) →
R4 (corrected files, dated notes, versions) → R6 (coverage) → R7
(demonstrations) → R8 (`ci-schema-gate`) → R9 (claims, errata) → evidence.**

R5 before R3 is not a preference: a generated file describing a layout that is
about to change is a file you will regenerate twice and review once.

## 2. R1 — what to measure, and the control each probe needs

- The eleven files, and the absence of the subcommand they name. **Control:** the
  same probe finding a subcommand that does exist.
- **The drift, per format, for all eleven** — the RFC measured one
  (`rollback-record-v1`). Field name, width, order, and fields absent from
  either side.
- The four `from_raw_parts` write sites in `fjell-init` (E-055), by line.
- **Whether any format is read back from disk, per format** — not "in general".
- `/usr/bin/grep -a` throughout: the shell's `grep` here silently skips
  NUL-containing files, which is what made E-046's "0 sites" wrong and E-055
  exist. **Control the specific file**, not the pattern.

## 3. R5 — the bytes, and the test that the bytes are clean

Serialise named fields, as RFC-0.32-002 D4 did for the checksums. The test is not
"the sector round-trips": it is that **no byte of the written sector is
indeterminate** — every byte traceable to a named field or to an explicitly
written constant. A sector buffer zeroed before filling is not a substitute for a
serialiser, and says nothing about padding inside the struct.

## 4. R8 — do not leave both instruments

`ci-schema-gate` checks that eleven paths exist and are non-empty, and says so in
its own comment. When D2's comparison runs, that job is either replaced by it or
retired. **Two instruments for one property is how a project ends up trusting the
weaker one.**

## 5. Prohibited

- A generator that hard-codes fields (§A) — escalate instead.
- A second grammar: do not write a parser for the `.frozen` DSL if
  generated-vs-committed text comparison is enough (§B).
- Migrating on-disk data, or changing any format's **design**.
- Touching the kernel's four raw reinterpretation sites.
- Regenerating a `.frozen` file without reading the diff.
- `cargo fmt --all --check` in your head.

## 6. Required evidence

1. R1's table, per format, with every control, and the read-back answer per
   format.
2. §A–§E in writing, §A engaging §0.1's alternative explicitly.
3. R5: the four sites, and the indeterminate-byte test.
4. R3: the generator, the comparison, the Gate 1 run, and **the byte-identical
   output** for an untouched format.
5. R4: each corrected file with its dated note; every version move justified.
6. R6: the coverage list, including each exclusion's reason.
7. R7's three demonstrations, each reverted, with transcripts.
8. R8: what happened to `ci-schema-gate`.
9. R9: ADR-v0.6-003 corrected; **E-045 and E-055** resolved or their survivors
   named, with `v1-limitations.md` in the same commit as the register.
10. The gates, each by **its own exit status** — never a gate piped into `grep` —
    `test-all`, the repro baseline re-recorded in the same commit as any rebuild,
    and a CI run id.

## 7. Review request

Standard format, in `.git-exclude/review-request/`. Flag for focused review:

- **§A's answer**, first, and what the generator reads.
- **The per-format drift table**, and anything the RFC's single example missed.
- **The indeterminate-byte test**, and why it is not merely a round-trip.
- Any format you found read back from disk.
- Anything you had to change outside the *Touches* list, which is indicative.
