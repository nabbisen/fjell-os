# RFC answers and investigations

Documents attached to an RFC, rather than RFCs themselves.

- **`*-answer.md`** — the written answer to the open questions an RFC posed,
  produced by the implementation before the code and reviewed with it. An RFC
  that opens questions is not implementable until its answer document exists.
- **`*-investigation.md`** — a question examined without a decision attached.

Both belong to the RFC named in the filename, and neither is an RFC: they are
not in the lifecycle folders and carry no Status of their own. The register
they most often cite is [`../ERRATA.md`](../ERRATA.md).

Moved here from `docs/rfcs/` by RFC-0.32-003 (D4, D22), which gave the RFC
corpus one root.
